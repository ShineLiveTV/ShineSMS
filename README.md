## How to run in Termux



Copy and paste the following commands one by one in your Termux:



```bash

pkg update && pkg upgrade -y

pkg install python git -y

pip install requests

git clone https://github.com/ShineLiveTV/ShineSMS

cd ShineSMS

python shinekoko_v2.py

```
